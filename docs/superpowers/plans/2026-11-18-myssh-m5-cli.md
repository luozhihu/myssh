# M5 — CLI, install/doctor, Agent injection Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reach CLI parity with `sshmng` M5: `ssh` (interactive + non-interactive, direct jumphost login), `file` (upload/download/dirs/relay), `install`, `doctor`, `version --check`, `update`, and MCP injection for Claude Code, CodeAgent, Hermes, and OpenCode — adapted to npx distribution.

**Architecture:** Commands stay thin: `src/cli/*` parses flags, resolves names, and formats output; connection/session/transfer behavior is reused from M2–M4. New CLI-only login entry points in `src/ssh/login.ts` accept `needShell`/`needSftp` so interactive relay never runs DetectShell/InjectRC and file transfer never pays for shell setup. Interactive terminals are driven by a testable `relayTerminal` over a `TerminalStreams` abstraction; file commands create short-lived `SessionManager` sessions. Agent injection is a set of async injectors sharing atomic-write/backup helpers, with `npx -y myssh@latest mcp` as the entry.

**Tech Stack:** TypeScript 7 strict ESM, Node ≥22, ssh2 1.17, vitest 5, `yaml` 2.x (new dependency), no CLI framework.

## Behavioral contract (ported from the Go code)

These values and messages are user-visible and must match `sshmng` unless marked npx-specific.

| Item | Exact value |
| --- | --- |
| Server-name resolution order | exact name → fuzzy (`name`/`addr`/`tags`, AND keywords, case-insensitive) → prompt if allowed |
| Single fuzzy match feedback | `matched: <name>\n` on **stderr** |
| Multi fuzzy, no prompt | `multiple servers match "<q>": a, b; specify exact name` |
| Multi fuzzy prompt header | `Multiple servers match:` then `  [N] <name padded 20> <addr padded 25> <tags,comma>` then `Select [1-N]: ` on stderr |
| Bad selection | `invalid selection "<value>" (expected 1-N)` |
| EOF selection | `no selection (EOF)` |
| No match | no server: `no server matches "<q>"`; both: `no server or jumphost matches "<q>"` |
| Raw + command | `Error: raw device: no unix shell, non-interactive mode not supported; use interactive mode` |
| Bastion + command | `Error: non-interactive command not supported for bastion "<j>" (ssh_j=false lands on an interactive menu, not a shell); use interactive mode: sshmng ssh <j>` |
| Non-interactive exit | print cleaned output verbatim (no added newline), process exit = command exit code |
| Upload success | `uploaded <local> -> <server>:<remote> (<n> bytes)` |
| Upload timeout | `uploaded <local> -> <server>:<remote> (timed out, <n> bytes transferred)` (exit 1) |
| Upload failure | `Error: upload <local> -> <server>:<remote>: <err>` |
| Local open failure | `Error: open <local>: <err>` |
| Download success | `downloaded <server>:<remote> -> <local> (<n> bytes)` |
| Download timeout | `downloaded <server>:<remote> -> <local> (timed out, <n> bytes transferred)` (exit 1) |
| Download failure | `Error: download <server>:<remote> -> <local>: <err>` |
| Dir summary | `<verb> <local> -> <server>:<remote> (<files> files, <bytes> bytes[, <n> skipped][, <n> renamed][, <n> timed out])` plus ` — partial: <err>` (em dash) |
| Relay per-dest ok | `<name>: ok (<n> bytes)` |
| Relay per-dest fail | `<name>: failed: <err>` |
| Relay summary | `relay <src-server> -> <n> destinations: <ok> ok, <failed> failed` |
| Relay no dest | `Error: no relay destinations connected (<n> failed)` |
| Relay source login fail | `Error: source <name>: <err>` |
| Relay dest login fail | `<name>: failed: <err>` (continues) |
| Pattern B sftp reason | `server <name> uses bastion mode (ssh_j=false); sftp lands on the jumphost, not the target — use a direct or ssh_j=true connection` |
| Other sftp reason | `sftp channel unavailable for <name> (server may not support the sftp subsystem)` |
| Install / doctor binary name | `sshmng` in headers (`sshmng doctor - verifying setup`) |
| Doctor exit | 0 all pass, 1 any FAIL, 2 WARN-only |
| Agent entry | `{command:"npx", args:["-y", "myssh@latest"|"myssh@<VERSION>", "mcp"], env:{SSHMNG_HOME:<home>}}` |
| Backup name | `<config>.bak.<YYYYMMDD-HHMMSS>` (local time) |
| Config skeleton | exact Go JSON (see Task 8) |
| npm registry | `https://registry.npmjs.org/myssh/latest` |
| Log / progress | always stderr; stdout is reserved for MCP JSON-RPC and normal CLI results |

Directory conflict policy default `overwrite` is already implemented in `src/sftp/dir.ts`; CLI only passes flags through. Session sftp-unavailable error is `sftp not available for this session` (M4).

```ts
/** Command-line flag parsing compatible with the Go pflag behavior we use. */

export class FlagError extends Error {
  constructor(message: string) {
    super(message);
    this.name = "FlagError";
  }
}

export interface FlagSpec {
  strings?: string[];
  numbers?: string[];
  booleans?: string[];
  arrays?: string[];
}

export interface ParsedFlags {
  strings: Map<string, string>;
  numbers: Map<string, number>;
  booleans: Set<string>;
  arrays: Map<string, string[]>;
  positionals: string[];
}

export function parseFlags(args: string[], spec: FlagSpec): ParsedFlags {
  const strings = new Map<string, string>();
  const numbers = new Map<string, number>();
  const booleans = new Set<string>();
  const arrays = new Map<string, string[]>();
  const boolNames = new Set([...(spec.booleans ?? []), "help"]);
  const stringNames = new Set(spec.strings ?? []);
  const numberNames = new Set(spec.numbers ?? []);
  const arrayNames = new Set(spec.arrays ?? []);
  const positionals: string[] = [];

  for (let index = 0; index < args.length; index += 1) {
    const arg = args[index]!;
    if (arg === "--") {
      positionals.push(...args.slice(index + 1));
      break;
    }
    if (arg === "-" || !arg.startsWith("-")) {
      positionals.push(arg);
      continue;
    }
    if (!arg.startsWith("--")) {
      throw new FlagError(`unknown flag: ${arg}`);
    }
    const equals = arg.indexOf("=");
    const name = equals >= 0 ? arg.slice(2, equals) : arg.slice(2);
    const inline = equals >= 0 ? arg.slice(equals + 1) : undefined;

    if (boolNames.has(name)) {
      if (inline !== undefined) {
        throw new FlagError(`flag --${name} does not take a value`);
      }
      booleans.add(name);
      continue;
    }

    const known = stringNames.has(name) || numberNames.has(name) || arrayNames.has(name);
    if (!known) {
      throw new FlagError(`unknown flag: --${name}`);
    }
    let value = inline;
    if (value === undefined) {
      index += 1;
      if (index >= args.length) {
        throw new FlagError(`flag --${name} requires a value`);
      }
      value = args[index]!;
    }
    if (stringNames.has(name)) {
      strings.set(name, value);
    } else if (numberNames.has(name)) {
      if (!/^[+-]?\d+$/.test(value)) {
        throw new FlagError(`invalid value for --${name}: ${value}`);
      }
      numbers.set(name, Number(value));
    } else {
      const list = arrays.get(name) ?? [];
      list.push(value);
      arrays.set(name, list);
    }
  }
  return { strings, numbers, booleans, arrays, positionals };
}

/** Extract `--config <path>` / `--config=<path>` from positional-style args. */
export function takeConfigFlag(args: string[]): { config?: string; rest: string[] } {
  const rest: string[] = [];
  let config: string | undefined;
  for (let index = 0; index < args.length; index += 1) {
    const arg = args[index]!;
    if (arg === "--config") {
      const value = args[index + 1];
      if (!value) throw new Error("--config requires a path");
      config = value;
      index += 1;
    } else if (arg.startsWith("--config=")) {
      config = arg.slice("--config=".length);
    } else {
      rest.push(arg);
    }
  }
  return { config, rest };
}
```

```ts
import { homedir } from "node:os";
import { createInterface, type Interface } from "node:readline/promises";

/** Local terminal hooks, injectable in tests. */
export interface TerminalHooks {
  stdin: NodeJS.ReadableStream;
  stdout: NodeJS.WritableStream;
  stderr?: NodeJS.WritableStream;
  isTTY: boolean;
  getWindowSize?(): { rows: number; cols: number } | undefined;
  onResize?(handler: () => void): () => void;
  setRawMode?(raw: boolean): void;
}

/** Everything a CLI command may need from the outside world. */
export interface IO {
  out(text: string): void;
  err(text: string): void;
  readLine?(): Promise<string | null>;
  env?: NodeJS.ProcessEnv;
  homeDir?: string;
  platform?: NodeJS.Platform;
  fetchImpl?: typeof fetch;
  now?: () => Date;
  stderrIsTTY?: boolean;
  terminal?: TerminalHooks;
}

let sharedReadline: Interface | undefined;

export const defaultIO: IO = {
  out: (text) => { process.stdout.write(text); },
  err: (text) => { process.stderr.write(text); },
  env: process.env,
  homeDir: homedir(),
  platform: process.platform,
  fetchImpl: globalThis.fetch,
  now: () => new Date(),
  stderrIsTTY: !!process.stderr.isTTY,
};

export function envOf(io: IO): NodeJS.ProcessEnv {
  return io.env ?? process.env;
}

export function homeOf(io: IO): string {
  return io.homeDir ?? homedir();
}

export function platformOf(io: IO): NodeJS.Platform {
  return io.platform ?? process.platform;
}

export function nowOf(io: IO): Date {
  return (io.now ?? (() => new Date()))();
}

export function stderrTTY(io: IO): boolean {
  return io.stderrIsTTY ?? !!process.stderr.isTTY;
}

export async function readLineOf(io: IO): Promise<string | null> {
  if (io.readLine) return io.readLine();
  sharedReadline ??= createInterface({ input: process.stdin, output: process.stdout });
  try {
    return await sharedReadline.question("");
  } catch {
    return null;
  }
}

export function terminalOf(io: IO): TerminalHooks {
  if (io.terminal) return io.terminal;
  const input = process.stdin;
  const output = process.stdout;
  return {
    stdin: input,
    stdout: output,
    stderr: process.stderr,
    isTTY: !!(input.isTTY && output.isTTY),
    getWindowSize: () => (
      output.isTTY ? { rows: output.rows, cols: output.columns } : undefined
    ),
    onResize: (handler) => {
      output.on("resize", handler);
      return () => { output.off("resize", handler); };
    },
    setRawMode: (raw) => {
      if (input.isTTY) input.setRawMode(raw);
    },
  };
}
```

```ts
/** Prompts over injected writers/readers so CLI tests never touch real stdio. */

export type WriteLine = (text: string) => void;
export type ReadLine = () => Promise<string | null>;

export interface ConfirmResult {
  confirmed: boolean;
  error?: Error;
}

export async function promptConfirm(
  write: WriteLine,
  read: ReadLine,
  message: string,
  defaultYes: boolean,
): Promise<ConfirmResult> {
  write(`${message}${defaultYes ? " [Y/n]: " : " [y/N]: "}`);
  const line = await read();
  if (line === null) {
    return { confirmed: false, error: new Error("no input (EOF)") };
  }
  const answer = line.trim().toLowerCase();
  if (answer === "") return { confirmed: defaultYes };
  if (answer === "y" || answer === "yes") return { confirmed: true };
  if (answer === "n" || answer === "no") return { confirmed: false };
  return {
    confirmed: false,
    error: new Error(`invalid input ${JSON.stringify(line)}`),
  };
}
```

```ts
import { PassThrough, Writable } from "node:stream";
import { describe, expect, it } from "vitest";
import { PtyConn } from "../../src/pty/pty_conn.js";
import { relayTerminal } from "../../src/pty/relay_terminal.js";
import { FakePtyTransport } from "../helpers/fake_pty.js";

function tick(ms = 20): Promise<void> {
  return new Promise((resolve) => setTimeout(resolve, ms));
}

function capture() {
  let text = "";
  const stream = new Writable({
    write(chunk, _enc, cb) { text += chunk.toString(); cb(); },
  });
  return { stream, get text() { return text; } };
}

function makeConn() {
  const transport = new FakePtyTransport();
  const conn = new PtyConn(transport, "ab12");
  return { transport, conn };
}

function makeTerminal() {
  const stdin = new PassThrough();
  const out = capture();
  const rawModes: boolean[] = [];
  let resizeHandler: (() => void) | undefined;
  return {
    stdin,
    out,
    rawModes,
    fireResize: () => resizeHandler?.(),
    streams: {
      stdin,
      stdout: out.stream,
      isTTY: true,
      getWindowSize: () => ({ rows: 24, cols: 80 }),
      onResize: (handler: () => void) => {
        resizeHandler = handler;
        return () => { resizeHandler = undefined; };
      },
      setRawMode: (raw: boolean) => { rawModes.push(raw); },
    },
  };
}

describe("relayTerminal", () => {
  it("flushes pending output, pumps both directions, and restores the terminal", async () => {
    const { transport, conn } = makeConn();
    transport.emit("early-prompt");
    const term = makeTerminal();

    const relay = relayTerminal(conn, term.streams, { echoDelayMs: 0 });

    expect(term.out.text).toBe("early-prompt");
```

```ts
/** Local terminal surface used by the relay; injectable in tests. */
export interface TerminalStreams {
  stdin: NodeJS.ReadableStream;
  stdout: NodeJS.WritableStream;
  isTTY: boolean;
  getWindowSize?(): { rows: number; cols: number } | undefined;
  onResize?(handler: () => void): () => void;
  setRawMode?(raw: boolean): void;
}

export interface RelayTerminalOptions {
  /** Sent once so a remote shell echoes typed input. */
  echoLine?: string;
  /** Delay after enabling echo before entering raw mode. */
  echoDelayMs?: number;
  signal?: AbortSignal;
}

function message(err: unknown): string {
  return err instanceof Error ? err.message : String(err);
}

export function delay(ms: number): Promise<void> {
  return new Promise((resolve) => {
    const timer = setTimeout(resolve, ms);
    timer.unref?.();
  });
}

/**
 * Bidirectional terminal relay. Mirrors Go PtyConn.Relay: flush pending
 * output, run `stty echo`, enter raw mode, pump stdin→PTY and PTY→stdout,
 * forward window resizes, and always restore the terminal + close the PTY.
 */
export async function relayTerminal(
  conn: PtyConn,
  term: TerminalStreams,
  options: RelayTerminalOptions = {},
): Promise<void> {
  const pending = conn.drainPending();
  if (pending.length > 0) term.stdout.write(pending);

  conn.send(options.echoLine ?? "stty echo\n");
  await delay(options.echoDelayMs ?? 50);

  let rawSet = false;
  if (term.isTTY) {
    try {
      term.setRawMode?.(true);
      rawSet = term.setRawMode !== undefined;
    } catch (err) {
      conn.close();
      throw new Error(`set terminal raw mode: ${message(err)}`);
    }
  }

  let finish!: () => void;
  const done = new Promise<void>((resolve) => { finish = resolve; });

  const onStdin = (chunk: Buffer | string): void => {
    const data = Buffer.isBuffer(chunk) ? chunk : Buffer.from(chunk);
    void conn.sendRaw(data).catch(() => finish());
  };
  const onStdinError = (): void => finish();
  const onAbort = (): void => finish();

  term.stdin.on("data", onStdin);
  term.stdin.once("end", finish);
  term.stdin.once("close", finish);
  term.stdin.once("error", onStdinError);
  options.signal?.addEventListener("abort", onAbort, { once: true });
  if (options.signal?.aborted) finish();

  const detachData = conn.onData((data) => { term.stdout.write(data); });
  const detachClose = conn.onClose(() => finish());

  const applySize = (): void => {
    const size = term.getWindowSize?.();
    if (size && size.rows > 0 && size.cols > 0) conn.resize(size.rows, size.cols);
  };
  applySize();
  const detachResize = term.onResize?.(applySize);

  try {
    await done;
  } finally {
    term.stdin.off("data", onStdin);
    term.stdin.off("end", finish);
    term.stdin.off("close", finish);
    term.stdin.off("error", onStdinError);
    options.signal?.removeEventListener("abort", onAbort);
    detachData();
    detachClose();
    detachResize?.();
    if (rawSet) {
      try { term.setRawMode?.(false); } catch { /* terminal gone */ }
    }
    conn.close();
  }
}
```

```ts
export interface ResolverIO {
  err(text: string): void;

function q(value: string): string {
  return JSON.stringify(value);
}

async function promptChoice<T extends { name: string; addr: string; tags?: string[] }>(
  matches: T[],
  noun: "servers" | "jumphosts",
  io: ResolverIO,
): Promise<T> {
  io.err(`Multiple ${noun} match:\n`);
  matches.forEach((item, index) => {
    const tags = (item.tags ?? []).join(",");
    io.err(
      `  [${index + 1}] ${item.name.padEnd(20)} ${item.addr.padEnd(25)} ${tags}\n`,
    );
  });
  io.err(`Select [1-${matches.length}]: `);
  const line = await io.readLine();
  if (line === null) throw new Error("no selection (EOF)");
  const input = line.trim();
  const index = Number(input);
  if (!Number.isInteger(index) || index < 1 || index > matches.length) {
    throw new Error(`invalid selection ${q(input)} (expected 1-${matches.length})`);
  }
  return matches[index - 1]!;
}

export async function resolveServer(
  cfg: Config,
  query: string,
  allowPrompt: boolean,
  io: ResolverIO,
): Promise<SSHServer> {
  const exact = cfg.servers.find((server) => server.name === query);
  if (exact) return exact;

  const matches = listSSHServers(cfg, query);
  if (matches.length === 0) throw new Error(`no server matches ${q(query)}`);
  if (matches.length === 1) {
    io.err(`matched: ${matches[0]!.name}\n`);
    return matches[0]!;
  }
  if (!allowPrompt) {
    throw new Error(
      `multiple servers match ${q(query)}: ${matches.map((m) => m.name).join(", ")}; specify exact name`,
    );
  }
  return promptChoice(matches, "servers", io);
}

export async function resolveJumphost(
  cfg: Config,
  query: string,
  allowPrompt: boolean,
  io: ResolverIO,
): Promise<Jumphost> {
  const exact = cfg.jumphosts.find((jump) => jump.name === query);
  if (exact) return exact;

  const matches = listJumphosts(cfg, query);
  if (matches.length === 0) throw new Error(`no jumphost matches ${q(query)}`);
  if (matches.length === 1) {
    io.err(`matched: ${matches[0]!.name}\n`);
    return matches[0]!;
  }
  if (!allowPrompt) {
    throw new Error(
      `multiple jumphosts match ${q(query)}: ${matches.map((m) => m.name).join(", ")}; specify exact name`,
    );
  }
  return promptChoice(matches, "jumphosts", io);
}

export type SSHTarget =
  | { kind: "server"; server: SSHServer }
  | { kind: "jumphost"; jump: Jumphost };

/** Server names take precedence; fall back to direct jumphost login. */
export async function resolveTarget(
  cfg: Config,
  query: string,
  allowPrompt: boolean,
  io: ResolverIO,
): Promise<SSHTarget> {
  try {
    return { kind: "server", server: await resolveServer(cfg, query, allowPrompt, io) };
  } catch {
    try {
      return { kind: "jumphost", jump: await resolveJumphost(cfg, query, allowPrompt, io) };
    } catch {
      throw new Error(`no server or jumphost matches ${q(query)}`);
    }
  }
}
```

```ts
import type { IO } from "./io.js";
import { nowOf, stderrTTY } from "./io.js";

const DEFAULT_WIDTH = 80;
const GAUGE_WIDTH = 20;
const THROTTLE_MS = 100;
const ELLIPSIS = "…";

export interface BarState {
  label: string;
  /** < 0 = unknown size. */
  total: number;
  current: number;
  filesTotal: number;
  filesDone: number;
  status: string;
  width: number;
  elapsedMs: number;
}

export function humanizeBytes(n: number): string {
  if (n < 1024) return `${n} B`;
  const units = ["KB", "MB", "GB", "TB"];
  let value = n / 1024;
  let index = 0;
  while (value >= 1024 && index < units.length - 1) {
    value /= 1024;
    index += 1;
  }
  return `${value.toFixed(1)} ${units[index]}`;
}

function cellWidth(codePoint: number): number {
  if (
    (codePoint >= 0x1100 && codePoint <= 0x115f)
    || codePoint >= 0x2e80
    || codePoint === 0x2329
    || codePoint === 0x232a
  ) {
    return 2;
  }
  return 1;
}

export function displayWidth(text: string): number {
  let width = 0;
  for (const char of text) width += cellWidth(char.codePointAt(0)!);
  return width;
}

export function truncateToWidth(text: string, maxWidth: number): string {
  if (maxWidth < 1) return "";
  if (displayWidth(text) <= maxWidth) return text;
  const slash = text.lastIndexOf("/");
  if (slash >= 0 && slash < text.length - 1) {
    const tail = text.slice(slash + 1);
    const candidate = `…/${tail}`;
    if (displayWidth(candidate) <= maxWidth) return candidate;
    return truncateToWidth(tail, maxWidth);
  }
  const limit = maxWidth - 1;
  let out = "";
  let width = 0;
  for (const char of text) {
    const charWidth = cellWidth(char.codePointAt(0)!);
    if (width + charWidth > limit) break;
    out += char;
    width += charWidth;
  }
  return out + ELLIPSIS;
}

function gaugeString(width: number, percent: number): string {
  if (width <= 0) return "";
  const filled = Math.floor((width * percent) / 100);
  return "█".repeat(filled) + "░".repeat(width - filled);
}

function joinNonEmpty(parts: string[], separator: string): string {
  return parts.filter((part) => part !== "").join(separator);
}

function fitLabelAndMeta(label: string, meta: string, width: number): string {
  const metaWidth = displayWidth(meta);
  const available = width - 2 - metaWidth;
  if (available < 1) {
    return metaWidth <= width ? meta : truncateToWidth(meta, width);
  }
  return `${truncateToWidth(label, available)}  ${meta}`;
}

export function renderBarLine(state: BarState): string {
  const width = state.width > 0 ? state.width : DEFAULT_WIDTH;
  const currentText = humanizeBytes(state.current);
  const rate = state.elapsedMs > 0 ? state.current / (state.elapsedMs / 1000) : 0;
  const rateText = `${humanizeBytes(Math.trunc(rate))}/s`;

  let tags = "";
  if (state.filesTotal > 0) {
    tags = `[${state.filesDone}/${state.filesTotal} files]`;
  }
  if (state.status !== "") {
    tags = tags === "" ? `[${state.status}]` : `${tags} [${state.status}]`;
  }

  if (state.total < 0) {
    const variants = [[rateText, tags], [rateText], []];
    for (const extra of variants) {
      const extraText = extra.length > 0 ? `  ${joinNonEmpty(extra, "  ")}` : "";
      const line = `${state.label}  ${currentText}${extraText}`;
      if (displayWidth(line) <= width) return line;
    }
    return fitLabelAndMeta(state.label, currentText, width);
  }

  const percent = state.total > 0
    ? Math.min(100, Math.floor((state.current / state.total) * 100))
    : 0;
  const totalText = humanizeBytes(state.total);
  const remaining = rate > 0 && state.current < state.total
    ? `${Math.floor((state.total - state.current) / rate)}s`
    : "—";
  const progressText = `${currentText}/${totalText}`;
  const percentText = `${percent}%`;

  const extraSets = [
    [percentText, progressText, rateText, `ETA ${remaining}`, tags],
    [percentText, progressText, rateText, `ETA ${remaining}`],
    [percentText, progressText, rateText],
    [percentText, progressText],
    [progressText],
  ];

  for (const extras of extraSets) {
    const meta = joinNonEmpty(extras, "  ");
    const metaWidth = displayWidth(meta);
    const labelWidth = displayWidth(state.label);
    for (let gaugeWidth = GAUGE_WIDTH; gaugeWidth >= 0; gaugeWidth -= 1) {
      const gauge = gaugeString(gaugeWidth, percent);
      const parts = gauge === "" ? [state.label] : [state.label, gauge];
      const nonEmpty = parts.length + (meta === "" ? 0 : 1);
      const separators = nonEmpty > 1 ? (nonEmpty - 1) * 2 : 0;
      const totalWidth = labelWidth + displayWidth(gauge) + metaWidth + separators;
      if (totalWidth <= width) {
        const all = meta === "" ? parts : [...parts, meta];
        return joinNonEmpty(all, "  ");
      }
    }
  }
  return fitLabelAndMeta(state.label, progressText, width);
}

export interface ProgressBarOptions {
  tty?: boolean;
  width?: number;
  now?: () => number;
}

/** TTY-gated single-line progress bar mirroring internal/progress.Bar. */
export class ProgressBar {
  private readonly tty: boolean;
  private readonly width: number;
  private readonly now: () => number;
  private readonly start: number;
  private lastDraw: number | undefined;
  private current = 0;
  private filesTotal = 0;
  private filesDone = 0;
  private status = "";
  private finished = false;

  constructor(
    private readonly write: (text: string) => void,
    private readonly label: string,
    private readonly total: number,
    options: ProgressBarOptions = {},
  ) {
    this.tty = options.tty ?? false;
    this.width = options.width ?? DEFAULT_WIDTH;
    this.now = options.now ?? (() => Date.now());
    this.start = this.now();
  }

  setFiles(totalFiles: number): this {
    this.filesTotal = totalFiles;
    return this;
  }

  setBytes(bytes: number): void {
    if (!this.tty || this.finished) return;
    this.current = bytes;
    this.maybeRedraw();
  }

  setFilesDone(files: number): void {
    if (!this.tty || this.finished) return;
    this.filesDone = files;
    this.maybeRedraw();
  }

  setStatus(status: string): void {
    if (!this.tty || this.finished) return;
    this.status = status;
    this.maybeRedraw();
  }

  finish(): void {
    if (this.finished) return;
    this.finished = true;
    if (this.tty) this.write("\r\x1b[J");
  }

  private maybeRedraw(): void {
    const now = this.now();
    if (
      this.lastDraw !== undefined
      && now - this.lastDraw < THROTTLE_MS
      && !(this.total > 0 && this.current >= this.total)
    ) {
      return;
    }
    this.lastDraw = now;
    const line = renderBarLine({
      label: this.label,
      total: this.total,
      current: this.current,
      filesTotal: this.filesTotal,
      filesDone: this.filesDone,
      status: this.status,
      width: this.width,
      elapsedMs: now - this.start,
    });
    this.write(`\r\x1b[J${line}`);
  }
}

/** Bar on stderr; silent unless stderr is a TTY. */
export function newBar(io: IO, label: string, total: number): ProgressBar {
  return new ProgressBar((text) => io.err(text), label, total, {
    tty: stderrTTY(io),
    now: () => nowOf(io).getTime(),
  });
}
```

```ts
  return `${trimmed}${separator(trimmed, platform)}${baseName(src, platform)}`;
}
```

```ts
/** Sum regular files under a remote tree; symlinks/errors are skipped. */
export async function remoteDirTotals(
  backend: SftpTransfer,
  remoteDir: string,
): Promise<{ bytes: number; files: number }> {
  let bytes = 0;
  let files = 0;
  async function visit(remotePath: string, known?: SftpStat): Promise<void> {
    let st = known;
    if (!st) {
      try {
        st = await backend.lstat(remotePath);
      } catch {
        return;
      }
    }
    if (st.isSymbolicLink) return;
    if (st.isDirectory) {
      let entries;
      try {
        entries = await backend.readdir(remotePath);
      } catch {
        return;
      }
      for (const entry of entries) {
        if (entry.name === "." || entry.name === "..") continue;
        await visit(path.posix.join(remotePath, entry.name), entry.stat);
      }
      return;
    }
    bytes += st.size;
    files += 1;
  }
  await visit(remoteDir);
  return { bytes, files };
}
```

```ts
import path from "node:path";

/** Local-tree totals for the upload-dir progress bar (Go localDirTotals). */
export async function localDirTotals(
  dir: string,
): Promise<{ bytes: number; files: number }> {
  let bytes = 0;
  let files = 0;
  let root;
  try {
    root = await stat(dir);
  } catch {
    return { bytes: 0, files: 0 };
  }
  if (!root.isDirectory()) return { bytes: root.size, files: 1 };

  async function visit(current: string): Promise<void> {
    let entries;
    try {
      entries = await readdir(current, { withFileTypes: true });
    } catch {
      return;
    }
    for (const entry of entries) {
      if (entry.isSymbolicLink()) continue;
      const full = path.join(current, entry.name);
      if (entry.isDirectory()) {
        await visit(full);
        continue;
      }
      try {
        bytes += (await stat(full)).size;
        files += 1;
      } catch {
        /* unreadable entries are skipped, matching filepath.Walk tolerance */
      }
    }
  }
  await visit(dir);
  return { bytes, files };
}
```

```ts
<name> is an SSH server name (supports name/addr/tag substring match, same as 'sshmng ssh').
Pattern B (bastion, ssh_j=false) does not support file transfer: sftp lands on the
jumphost, not the target. Use a direct or ssh_j=true connection.
`;

function message(err: unknown): string {
  return err instanceof Error ? err.message : String(err);
}

function parseOrReport(
  args: string[],
  spec: Parameters<typeof parseFlags>[1],
  io: IO,
): ReturnType<typeof parseFlags> | undefined {
  try {
    return parseFlags(args, spec);
  } catch (err) {
    io.out(`${message(err)}\n`);
    return undefined;
  }
}

function positionalError(io: IO, count: number, expected: string): void {
  io.out(`Error: expected 3 positional args (${expected}), got ${count}\n`);
}

export async function runFileCmd(args: string[], io: IO): Promise<number> {
  if (args.length === 0) {
    io.out(FILE_USAGE);
    return 2;
  }
  switch (args[0]) {
    case "upload":
      return runUpload(args.slice(1), io);
    case "download":
      return runDownload(args.slice(1), io);
    case "upload-dir":
      return runUploadDir(args.slice(1), io);
    case "download-dir":
      return runDownloadDir(args.slice(1), io);
    case "relay":
      return runRelay(args.slice(1), io);
    default:
      io.out(
        `Unknown file subcommand ${JSON.stringify(args[0])}. Use 'upload', 'download', 'upload-dir', 'download-dir', or 'relay'.\n`,
      );
      io.out(FILE_USAGE);
      return 2;
  }
}

const SINGLE_USAGE = {
  upload: "Usage: sshmng file upload <name> <local> <remote> [--timeout <ms>] [--config <path>]\n",
  download: "Usage: sshmng file download <name> <remote> <local> [--timeout <ms>] [--config <path>]\n",
};

async function runUpload(args: string[], io: IO): Promise<number> {
  const flags = parseOrReport(args, { strings: ["config"], numbers: ["timeout"], booleans: [], arrays: [] }, io);
  if (!flags) return 2;
  if (flags.positionals.length !== 3) {
    io.out(SINGLE_USAGE.upload);
    if (flags.positionals.length !== 0) {
      positionalError(io, flags.positionals.length, "name local remote");
    }
    return 2;
  }
  const [name, local, remoteArg] = flags.positionals as [string, string, string];
  const timeout = flags.numbers.get("timeout") ?? 0;
  return withFileSession({ config: flags.strings.get("config"), name }, io, async (ctx) => {
    let fh;
    try {
      fh = await open(local, "r");
    } catch (err) {
      io.out(`Error: open ${local}: ${message(err)}\n`);
      return 1;
    }
    try {
      let size = -1;
      try { size = (await fh.stat()).size; } catch { /* indeterminate bar */ }
      const remote = resolveDstPath(
        local,
        remoteArg,
        remoteArg.endsWith("/"),
        platformOf(io),
      );
      const bar = newBar(io, `${ctx.server.name}:${remote}`, size);
      let outcome;
      try {
        outcome = await ctx.session.upload(
          fh.createReadStream({ autoClose: true }),
          remote,
          timeout,
          (bytes) => bar.setBytes(bytes),
        );
      } catch (err) {
        bar.finish();
        io.out(`Error: upload ${local} -> ${ctx.server.name}:${remote}: ${message(err)}\n`);
        return 1;
      }
      bar.finish();
      if (outcome.error && !outcome.timedOut) {
        io.out(`Error: upload ${local} -> ${ctx.server.name}:${remote}: ${outcome.error.message}\n`);
        return 1;
      }
      if (outcome.timedOut) {
        io.out(
          `uploaded ${local} -> ${ctx.server.name}:${remote} (timed out, ${outcome.bytes} bytes transferred)\n`,
        );
        return 1;
      }
      io.out(`uploaded ${local} -> ${ctx.server.name}:${remote} (${outcome.bytes} bytes)\n`);
      return 0;
    } finally {
      try { await fh.close(); } catch { /* stream may have closed it */ }
    }
  });
}

async function runDownload(args: string[], io: IO): Promise<number> {
  const flags = parseOrReport(args, { strings: ["config"], numbers: ["timeout"], booleans: [], arrays: [] }, io);
  if (!flags) return 2;
  if (flags.positionals.length !== 3) {
    io.out(SINGLE_USAGE.download);
    if (flags.positionals.length !== 0) {
      positionalError(io, flags.positionals.length, "name remote local");
    }
    return 2;
  }
  const [name, remote, localArg] = flags.positionals as [string, string, string];
  const timeout = flags.numbers.get("timeout") ?? 0;
  return withFileSession({ config: flags.strings.get("config"), name }, io, async (ctx) => {
    let localIsDir = localArg === "."
      || localArg.endsWith("/")
      || localArg.endsWith("\\");
    if (!localIsDir) {
      try {
        localIsDir = (await statLocal(localArg)).isDirectory();
      } catch {
        localIsDir = false;
      }
    }
    const local = resolveDstPath(remote, localArg, localIsDir, platformOf(io));
    let size = -1;
    try { size = (await ctx.session.stat(remote)).size; } catch { /* indeterminate */ }
    const bar = newBar(io, `${ctx.server.name}:${remote}`, size);
    let outcome;
    try {
      outcome = await ctx.session.downloadToFile(remote, local, timeout, (bytes) => bar.setBytes(bytes));
    } catch (err) {
      bar.finish();
      io.out(`Error: download ${ctx.server.name}:${remote} -> ${local}: ${message(err)}\n`);
      return 1;
    }
    bar.finish();
    if (outcome.error && !outcome.timedOut) {
      io.out(`Error: download ${ctx.server.name}:${remote} -> ${local}: ${outcome.error.message}\n`);
      return 1;
    }
    if (outcome.timedOut) {
      io.out(
        `downloaded ${ctx.server.name}:${remote} -> ${local} (timed out, ${outcome.bytes} bytes transferred)\n`,
      );
      return 1;
    }
    io.out(`downloaded ${ctx.server.name}:${remote} -> ${local} (${outcome.bytes} bytes)\n`);
    return 0;
  });
}

function printDirResult(
  io: IO,
  verb: string,
  local: string,
  serverName: string,
  remote: string,
  result: DirTransferResult,
  error?: Error,
): void {
  let text = `${verb} ${local} -> ${serverName}:${remote} (${result.files} files, ${result.bytes} bytes`;
  if (result.skipped > 0) text += `, ${result.skipped} skipped`;
  if (result.renamed > 0) text += `, ${result.renamed} renamed`;
  if (result.timedOut > 0) text += `, ${result.timedOut} timed out`;
  text += ")";
  if (error) text += ` — partial: ${error.message}`;
  io.out(`${text}\n`);
}

interface DirFlags {
  config?: string;
  conflict: string;
  concurrency: number;
  timeout: number;
  rest: string[];
}

function parseDirFlags(args: string[], io: IO): DirFlags | undefined {
  const flags = parseOrReport(args, {
    strings: ["config", "conflict"],
    numbers: ["concurrency", "timeout"],
    booleans: [],
    arrays: [],
  }, io);
  if (!flags) return undefined;
  return {
    config: flags.strings.get("config"),
    conflict: flags.strings.get("conflict") ?? "overwrite",
    concurrency: flags.numbers.get("concurrency") ?? 0,
    timeout: flags.numbers.get("timeout") ?? 0,
    rest: flags.positionals,
  };
}

async function runUploadDir(args: string[], io: IO): Promise<number> {
  const flags = parseDirFlags(args, io);
  if (!flags) return 2;
  if (flags.rest.length !== 3) {
    io.out(
      "Usage: sshmng file upload-dir <name> <local> <remote> [--conflict overwrite|skip|rename] [--concurrency N] [--timeout <ms>] [--config <path>]\n",
    );
    if (flags.rest.length !== 0) positionalError(io, flags.rest.length, "name local remote");
    return 2;
  }
  const [name, local, remote] = flags.rest as [string, string, string];
  return withFileSession({ config: flags.config, name }, io, async (ctx) => {
    const totals = await localDirTotals(local);
    const bar = newBar(io, `${ctx.server.name}:${remote}`, totals.bytes);
    if (totals.files > 0) bar.setFiles(totals.files);
    const outcome = await ctx.session.uploadDir(local, remote, {
      conflict: parseConflictPolicy(flags.conflict),
      concurrency: flags.concurrency,
      timeoutMs: flags.timeout,
      onProgress: (bytes, files) => {
        bar.setBytes(bytes);
        bar.setFilesDone(files);
      },
    });
    bar.finish();
    printDirResult(io, "uploaded", local, ctx.server.name, remote, outcome.result, outcome.error);
    return outcome.error ? 1 : 0;
  });
}

async function runDownloadDir(args: string[], io: IO): Promise<number> {
  const flags = parseDirFlags(args, io);
  if (!flags) return 2;
  if (flags.rest.length !== 3) {
    io.out(
      "Usage: sshmng file download-dir <name> <remote> <local> [--conflict overwrite|skip|rename] [--concurrency N] [--timeout <ms>] [--config <path>]\n",
    );
    if (flags.rest.length !== 0) positionalError(io, flags.rest.length, "name remote local");
    return 2;
  }
  const [name, remote, local] = flags.rest as [string, string, string];
  return withFileSession({ config: flags.config, name }, io, async (ctx) => {
    const totals = await ctx.session.remoteDirTotals(remote);
    const bar = newBar(io, `${ctx.server.name}:${remote}`, totals.bytes);
    if (totals.files > 0) bar.setFiles(totals.files);
    const outcome = await ctx.session.downloadDir(remote, local, {
      conflict: parseConflictPolicy(flags.conflict),
      concurrency: flags.concurrency,
      timeoutMs: flags.timeout,
      onProgress: (bytes, files) => {
        bar.setBytes(bytes);
        bar.setFilesDone(files);
      },
    });
    bar.finish();
    printDirResult(io, "downloaded", local, ctx.server.name, remote, outcome.result, outcome.error);
    return outcome.error ? 1 : 0;
  });
}

async function runRelay(args: string[], io: IO): Promise<number> {
  const flags = parseOrReport(args, {
    strings: ["config"],
    numbers: ["timeout"],
    booleans: [],
    arrays: ["to"],
  }, io);
  if (!flags) return 2;
  if (flags.positionals.length !== 3) {
    io.out(
      "Usage: sshmng file relay <src-name> <src-path> <dst-path> --to <dst1,dst2,...> [--timeout <ms>] [--config <path>]\n",
    );
    if (flags.positionals.length !== 0) {
      positionalError(io, flags.positionals.length, "src-name src-path dst-path");
    }
    return 2;
  }
  const to = (flags.arrays.get("to") ?? []).flatMap((value) => value.split(","));
  if (to.length === 0) {
    io.out(
      "Usage: sshmng file relay <src-name> <src-path> <dst-path> --to <dst1,dst2,...> [--timeout <ms>] [--config <path>]\n",
    );
    io.out("Error: --to is required (one or more destination server names)\n");
    return 2;
  }
  const [srcName, srcPath, dstPath] = flags.positionals as [string, string, string];
  const timeout = flags.numbers.get("timeout") ?? 0;
  const loaded = await loadRelayConfig(flags.strings.get("config"), io);
  if (typeof loaded === "number") return loaded;

  const manager = new SessionManager();
  try {
    let src;
    try {
      src = await loginFileSession(manager, {
        cfg: loaded.cfg,
        configPath: loaded.configPath,
        name: srcName,
        allowPrompt: true,
        io,
      });
    } catch (err) {
      io.out(`Error: source ${srcName}: ${message(err)}\n`);
      return 1;
    }

    const dstSids: string[] = [];
    const dstNames = new Map<string, string>();
    for (const dstName of to) {
      try {
        const login = await loginFileSession(manager, {
          cfg: loaded.cfg,
          configPath: loaded.configPath,
          name: dstName,
          allowPrompt: false,
          io,
        });
        dstSids.push(login.sid);
        dstNames.set(login.sid, dstName);
      } catch (err) {
        io.out(`${dstName}: failed: ${message(err)}\n`);
      }
    }
    if (dstSids.length === 0) {
      io.out(`Error: no relay destinations connected (${to.length} failed)\n`);
      return 1;
    }

    let size = -1;
    try { size = (await src.session.stat(srcPath)).size; } catch { /* indeterminate */ }
    const bar = newBar(io, src.server.name, size);
    let ok = 0;
    let failed = 0;
    let inFlight = dstSids.length;
    const updateStatus = (): void => {
      bar.setStatus(`${ok}✓ ${failed}✗ ${inFlight}⏳`);
    };
    updateStatus();

    const result = await manager.relayTransfer(
      src.sid,
      srcPath,
      dstSids,
      dstPath,
      timeout,
      {
        onDownloadedBytes: (bytes) => bar.setBytes(bytes),
        onDestinationDone: (_sid, destinationOk) => {
          inFlight -= 1;
          if (destinationOk) ok += 1;
          else failed += 1;
          updateStatus();
        },
      },
    );
    bar.finish();

    let okCount = 0;
    for (const destination of result.destinations) {
      const name = destination.dstServer || dstNames.get(destination.dstSid) || "";
      if (destination.ok) {
        io.out(`${name}: ok (${destination.bytes} bytes)\n`);
        okCount += 1;
      } else {
        io.out(`${name}: failed: ${destination.error ?? "unknown error"}\n`);
      }
    }
    io.out(
      `relay ${src.server.name} -> ${to.length} destinations: ${okCount} ok, ${to.length - okCount} failed\n`,
    );
    return okCount < to.length ? 1 : 0;
  } catch (err) {
    io.out(`Error: ${message(err)}\n`);
    return 1;
  } finally {
    manager.closeAll();
  }
}
```

```ts
export async function writeSecureFile(filePath: string, data: string): Promise<void> {
  try {
    await fs.writeFile(filePath, data, { mode: 0o600 });
  } catch (err) {
    throw new Error(`write ${filePath}: ${message(err)}`);
  }
  if (process.platform !== "win32") {
    try {
      await fs.chmod(filePath, 0o600);
    } catch (err) {
      throw new Error(`chmod ${filePath}: ${message(err)}`);
    }
  }
}

/** Create <home>/, config.json (preserved), config.example.json (rewritten). */
export async function scaffoldHome(
  home: string,
  options: ScaffoldOptions,
): Promise<void> {
  try {
    await fs.mkdir(home, { recursive: true, mode: 0o700 });
  } catch (err) {
    throw new Error(`mkdir ${home}: ${message(err)}`);
  }
  if (process.platform !== "win32") {
    try {
      await fs.chmod(home, 0o700);
    } catch (err) {
      throw new Error(`chmod ${home}: ${message(err)}`);
    }
  }

  const configPath = path.join(home, "config.json");
  if (options.overwriteConfig) {
    await writeSecureFile(configPath, configJSONSkeleton);
  } else {
    try {
      await fs.stat(configPath);
    } catch (err) {
      if ((err as NodeJS.ErrnoException).code !== "ENOENT") throw err;
      await writeSecureFile(configPath, configJSONSkeleton);
    }
  }

  await writeSecureFile(path.join(home, "config.example.json"), configExampleJSON);
}

}
```

```ts
import { promises as fs } from "node:fs";
import path from "node:path";

function message(err: unknown): string {
  return err instanceof Error ? err.message : String(err);
}

function pad(value: number): string {
  return String(value).padStart(2, "0");
}

/** Local-time YYYYMMDD-HHMMSS, matching Go's 20060102-150405. */
export function backupStamp(now: Date = new Date()): string {
  return [
    now.getFullYear(),
    pad(now.getMonth() + 1),
    pad(now.getDate()),
    "-",
    pad(now.getHours()),
    pad(now.getMinutes()),
    pad(now.getSeconds()),
  ].join("");
}

/** Copy path to <path>.bak.<stamp>; missing file is a no-op. */
export async function backupFile(filePath: string, now: Date = new Date()): Promise<void> {
  let data: Buffer;
  try {
    data = await fs.readFile(filePath);
  } catch (err) {
    if ((err as NodeJS.ErrnoException).code === "ENOENT") return;
    throw new Error(`stat ${filePath}: ${message(err)}`);
  }
  const backupPath = `${filePath}.bak.${backupStamp(now)}`;
  try {
    await fs.writeFile(backupPath, data, { mode: 0o600 });
  } catch (err) {
    throw new Error(`write backup ${backupPath}: ${message(err)}`);
  }
}

/** Restore path from the newest <path>.bak.* sibling (Windows rename fallback). */
export async function restoreFromBackup(filePath: string): Promise<void> {
  const dir = path.dirname(filePath);
  const prefix = `${path.basename(filePath)}.bak.`;
  let names: string[];
  try {
    names = (await fs.readdir(dir)).filter((name) => name.startsWith(prefix));
  } catch (err) {
    throw new Error(`glob backups: ${message(err)}`);
  }
  if (names.length === 0) {
    throw new Error(`no backup found matching ${filePath}.bak.*`);
  }
  let newest = names[0]!;
  let newestTime = 0;
  for (const name of names) {
    const info = await fs.stat(path.join(dir, name));
    if (info.mtimeMs > newestTime) {
      newest = name;
      newestTime = info.mtimeMs;
    }
  }
  const source = path.join(dir, newest);
  const data = await fs.readFile(source);
  await fs.writeFile(filePath, data, {
    mode: process.platform === "win32" ? 0o644 : 0o600,
  });
}

export interface AtomicWriteOptions {
  tempPrefix: string;
  platform?: NodeJS.Platform;
}

/** Temp file in the same dir, chmod 0600, rename; Windows remove-retry. */
export async function writeFileAtomic(
  filePath: string,
  data: string,
  options: AtomicWriteOptions,
): Promise<void> {
  const platform = options.platform ?? process.platform;
  const dir = path.dirname(filePath);
  try {
    await fs.mkdir(dir, { recursive: true, mode: 0o700 });
  } catch (err) {
    throw new Error(`mkdir ${dir}: ${message(err)}`);
  }
  const suffix = `${process.pid}-${Date.now()}`;
  const tempPath = path.join(dir, `${options.tempPrefix}.${suffix}`);
  try {
    await fs.writeFile(tempPath, data, { mode: 0o600 });
    if (platform !== "win32") await fs.chmod(tempPath, 0o600);
  } catch (err) {
    await fs.rm(tempPath, { force: true }).catch(() => undefined);
    throw new Error(`write temp: ${message(err)}`);
  }
  try {
    await fs.rename(tempPath, filePath);
    return;
  } catch (err) {
    if (platform !== "win32") {
      await fs.rm(tempPath, { force: true }).catch(() => undefined);
      throw new Error(
        `rename temp to ${filePath}: ${message(err)} (backup at ${filePath}.bak.<ts> if exists)`,
      );
    }
    try {
      await fs.rm(filePath, { force: true });
      await fs.rename(tempPath, filePath);
      return;
    } catch (retryErr) {
      let restore = "ok";
      try {
        await restoreFromBackup(filePath);
      } catch (restoreErr) {
        restore = message(restoreErr);
      }
      throw new Error(
        `rename temp to ${filePath}: ${message(retryErr)} (restore from backup: ${restore}; backup at ${filePath}.bak.<ts>)`,
      );
    }
  }
}
```

```ts
function message(err: unknown): string {

}

export async function loadJSONMap(
  filePath: string,
): Promise<Record<string, unknown>> {
  let data: string;
  try {
    data = await fs.readFile(filePath, "utf8");
  } catch (err) {
    if ((err as NodeJS.ErrnoException).code === "ENOENT") return {};
    throw new Error(`read ${filePath}: ${message(err)}`);
  }
  if (data.length === 0) return {};
  let parsed: unknown;
  try {
    parsed = JSON.parse(data);
  } catch (err) {
    throw new Error(`parse ${filePath} as JSON: ${message(err)}`);
  }
  if (parsed === null || typeof parsed !== "object" || Array.isArray(parsed)) {
    throw new Error(`parse ${filePath} as JSON: top level must be an object`);
  }
  return parsed as Record<string, unknown>;
}

export async function writeJSONMapAtomic(
  filePath: string,
  value: Record<string, unknown>,
  options: AtomicWriteOptions,
): Promise<void> {
  await writeFileAtomic(filePath, `${JSON.stringify(value, null, 2)}\n`, options);
}

export function mergeEntry(
  root: Record<string, unknown>,
  topKey: string,
  entry: Record<string, unknown>,
): void {
  const current = root[topKey];
  const servers = current !== null && typeof current === "object" && !Array.isArray(current)
    ? { ...(current as Record<string, unknown>) }
    : {};
  servers.sshmng = entry;
  root[topKey] = servers;
}

export function argsEqual(got: unknown, want: string[]): boolean {
  if (!Array.isArray(got)) return want.length === 0;
  if (got.length !== want.length) return false;
  return got.every((value, index) => value === want[index]);
}
```

```ts
      return new Error(
```

```ts
import { existsSync, promises as fs } from "node:fs";
import path from "node:path";
import { Store } from "../config/store.js";
import type { Config } from "../config/types.js";
import { VERSION } from "../version.js";
import { buildEntry, expectedEntries } from "./agent/entry.js";
import { createInjectors, verifyAny } from "./agent/registry.js";
import type { MCPEntry } from "./agent/types.js";
import { parseFlags } from "./flags.js";
import { defaultHome } from "./files.js";
import { envOf, homeOf, platformOf, type IO } from "./io.js";

export interface DoctorOptions {
  home?: string;
  agentFilter?: string[];
  expectedEntries?: MCPEntry[];
  findNpx?: () => Promise<string | null>;
  nodeVersion?: string;
}

function message(err: unknown): string {
  return err instanceof Error ? err.message : String(err);
}

function findOnPath(name: string, env: NodeJS.ProcessEnv): string | null {
  const dirs = (env.PATH ?? "").split(path.delimiter).filter(Boolean);
  const suffixes = process.platform === "win32" ? [".cmd", ".exe", ""] : [""];
  for (const dir of dirs) {
    for (const suffix of suffixes) {
      const candidate = path.join(dir, `${name}${suffix}`);
      if (existsSync(candidate)) return candidate;
    }
  }
  return null;
}

export async function runDoctor(
  args: string[],
  io: IO,
  options: DoctorOptions = {},
): Promise<number> {
  let filter = options.agentFilter;
  if (args.length > 0) {
    let flags;
    try {
      flags = parseFlags(args, {
        strings: ["agent"],
        numbers: [],
        booleans: [],
        arrays: [],
      });
    } catch (err) {
      io.out(`${message(err)}\n`);
      return 2;
    }
    if (flags.positionals.length > 0) {
      io.out(`Error: unexpected args: ${flags.positionals.join(" ")}\n`);
      return 2;
    }
    const agent = flags.strings.get("agent");
    if (agent) filter = agent.split(",").map((name) => name.trim());
  }
  return runDoctorChecks(io, { ...options, agentFilter: filter });
}

async function runDoctorChecks(io: IO, options: DoctorOptions): Promise<number> {
  const env = envOf(io);
  const home = options.home ?? defaultHome(env, homeOf(io));
  const platform = platformOf(io);
  const expected = options.expectedEntries ?? expectedEntries(home);
  const findNpx = options.findNpx ?? (() => Promise.resolve(findOnPath("npx", env)));
  const nodeVersion = options.nodeVersion ?? process.versions.node;

  let passCount = 0;
  let failCount = 0;
  let warnCount = 0;
  const print = (level: "OK" | "FAIL" | "WARN", text: string): void => {
    io.out(`  [${level}]  ${text}\n`);
    if (level === "FAIL") failCount += 1;
    else if (level === "WARN") warnCount += 1;
    else passCount += 1;
  };

  io.out("sshmng doctor - verifying setup\n\nHome:\n");

  let homeInfo;
  try {
    homeInfo = await fs.stat(home);
  } catch {
    homeInfo = undefined;
  }
  if (!homeInfo) {
    print("FAIL", `${home} missing - run 'sshmng install' to create`);
  } else if (!homeInfo.isDirectory()) {
    print("FAIL", `${home} is not a directory`);
  } else if (platform !== "win32") {
    const perm = homeInfo.mode & 0o777;
    if (perm !== 0o700) {
      print("FAIL", `${home} perm ${perm.toString(8)}, want 0700 (chmod 700 ${home})`);
    } else {
      print("OK", `${home} exists, 0700`);
    }
  } else {
    print("WARN", `${home} exists; manually restrict NTFS ACL (Properties -> Security)`);
  }

  const configPath = path.join(home, "config.json");
  let cfg: Config | undefined;
  let configLoaded = false;
  let configExists = false;
  try {
    await fs.stat(configPath);
    configExists = true;
  } catch {
    configExists = false;
  }
  if (!configExists) {
    print("FAIL", `${configPath} missing - run 'sshmng install'`);
  } else {
    try {
      cfg = await new Store(configPath).load();
      configLoaded = true;
    } catch (err) {
      print("FAIL", `config.json invalid: ${message(err)}`);
    }
    if (configLoaded) {
      if (platform !== "win32") {
        const info = await fs.stat(configPath);
        const perm = info.mode & 0o777;
        if (perm !== 0o600) {
          print("FAIL", `config.json perm ${perm.toString(8)}, want 0600 (chmod 600 ${configPath})`);
        } else {
          print("OK", `${configPath} exists, 0600, loads OK`);
        }
      } else {
        print("OK", `${configPath} exists, loads OK`);
      }
    }
  }

  const examplePath = path.join(home, "config.example.json");
  if (existsSync(examplePath)) print("OK", `${examplePath} exists`);
  else {
    print("WARN", `${examplePath} missing (optional, run 'sshmng install' to regenerate)`);
  }

  io.out("\nUpdate source:\n");
  if (configLoaded && cfg) {
    if (!cfg.update_url) {
      print("OK", "update_url: not configured (using GitHub Releases)");
    } else {
      let failure: string | undefined;
      try {
        const url = new URL(cfg.update_url);
        if (url.username !== "" || url.password !== "") {
          failure = "invalid update_url: embedded credentials are not allowed";
        } else if (
          (url.protocol !== "http:" && url.protocol !== "https:") || url.host === ""
        ) {
          failure =
            "invalid update_url: must be http:// or https:// URL with host (value redacted)";
        }
      } catch {
        failure =
          "invalid update_url: must be http:// or https:// URL with host (value redacted)";
      }
      if (failure) print("FAIL", failure);
      else print("OK", `update_url: ${cfg.update_url}`);
    }
  }

  if (VERSION === "dev") {
    print("WARN", "version not set at build time; this is a dev build. Self-update disabled.");
  } else {
    print("OK", `version: ${VERSION}`);
  }

  const major = Number.parseInt(nodeVersion.split(".")[0] ?? "0", 10);
  if (!Number.isFinite(major) || major < 22) {
    print("FAIL", `node ${nodeVersion} is too old; install Node.js >= 22`);
  } else {
    print("OK", `node ${nodeVersion}`);
  }
  const npxPath = await findNpx();
  if (npxPath) print("OK", "npx on PATH");
  else print("FAIL", "npx not found on PATH - install Node.js >= 22 (includes npx)");

  const knownHosts = path.join(home, "known_hosts");
  try {
    const info = await fs.stat(knownHosts);
    if (platform !== "win32") {
      const perm = info.mode & 0o777;
      if (perm !== 0o600) {
        print("FAIL", `known_hosts perm ${perm.toString(8)}, want 0600 (chmod 600 ${knownHosts})`);
      } else {
        print("OK", "known_hosts: 0600");
      }
    } else {
      print("OK", "known_hosts exists");
    }
  } catch {
    /* absent is fine: created on first connection */
  }

  io.out("\nAgents:\n");
  const ctx = { homeDir: homeOf(io), env, platform };
  for (const injector of createInjectors(ctx)) {
    if (options.agentFilter && options.agentFilter.length > 0
      && !options.agentFilter.includes(injector.name)) {
      continue;
    }
    const detection = await injector.detect(ctx);
    io.out(`  ${injector.displayName} (${detection.path})\n`);
    if (!detection.installed) {
      io.out(
        `    [SKIP]  not detected (install ${injector.displayName} or pass --agent ${injector.name} to force)\n`,
      );
      continue;
    }
    const err = await verifyAny(injector, detection.path, expected);
    if (err) print("FAIL", `${injector.displayName}: ${err.message}`);
    else print("OK", `${injector.displayName} config has sshmng entry, command/args/env match`);
  }

  io.out(
    `\nSummary: ${passCount} passed, ${failCount} failed, ${warnCount} warning(s)\n`,
  );
  if (failCount > 0) return 1;
  if (warnCount > 0) return 2;
  return 0;
}
```

```ts
function core(version: string): number[] {
  const cleaned = version.trim().replace(/^v/i, "").split("-")[0] ?? "";
  const parts = cleaned.split(".");
  return [0, 1, 2].map((index) => {
    const value = Number.parseInt(parts[index] ?? "0", 10);
    return Number.isFinite(value) ? value : 0;
  });
}

/** Semver-ish comparison ignoring prerelease tags. */
export function isNewer(latest: string, current: string): boolean {
  const a = core(latest);
  const b = core(current);
  for (let index = 0; index < 3; index += 1) {
    if (a[index]! !== b[index]!) return a[index]! > b[index]!;
  }
  return false;
}
```

```ts
import { BUILD_DATE, COMMIT, goArch, goOS, VERSION } from "../version.js";
import { parseFlags } from "./flags.js";

function message(err: unknown): string {
  return err instanceof Error ? err.message : String(err);
}

export async function runVersionCmd(
  args: string[],
  io: IO,
  version: string = VERSION,
): Promise<number> {
  let flags;
  try {
    flags = parseFlags(args, {
      strings: [],
      numbers: [],
      booleans: ["check"],
      arrays: [],
    });
  } catch (err) {
    io.out(`${message(err)}\n`);
    return 2;
  }
  if (flags.positionals.length > 0) {
    io.out(`Error: unexpected args: ${flags.positionals.join(" ")}\n`);
    return 2;
  }

  io.out(`sshmng ${version} (${goOS(platformOf(io))}/${goArch(process.arch)})\n`);
  io.out(`commit: ${COMMIT}\n`);
  io.out(`built:  ${BUILD_DATE}\n`);
  if (!flags.booleans.has("check")) return 0;

  const fetchImpl = io.fetchImpl ?? fetch;
  let latest: string;
  try {
    const response = await fetchImpl(REGISTRY_LATEST);
    if (!response.ok) throw new Error(`HTTP ${response.status}`);
    const body = await response.json() as { version?: unknown };
    if (typeof body.version !== "string" || body.version === "") {
      throw new Error("latest response has no version");
    }
    latest = body.version;
  } catch (err) {
    io.out(`[WARN] remote check failed: ${message(err)}\n`);
    return 0;
  }

  if (isNewer(latest, version)) {
    io.out(`Checking latest release ... latest is ${latest}\n`);
    io.out(`Update available: ${version} -> ${latest}\n`);
    io.out("Run 'myssh update' to apply.\n");
  } else {
    io.out("Checking latest release ... already at latest\n");
  }
  return 0;
}
```

```ts
export interface InstallOptions {
  findNpx?: DoctorOptions["findNpx"];
  nodeVersion?: string;
  version?: string;

function message(err: unknown): string {

async function promptAgentSelection(
  io: IO,
  injectors: AgentInjector[],
  ctx: AgentContext,
): Promise<AgentInjector[]> {
  const items: Array<{ injector: AgentInjector; selected: boolean; path: string }> = [];
  for (const injector of injectors) {
    const detection = await injector.detect(ctx);
    items.push({ injector, selected: detection.installed, path: detection.path });
  }
  for (;;) {
    io.out("\nDetected Agents:\n");
    items.forEach((item, index) => {
      io.out(
        `  [${item.selected ? "*" : " "}] ${index + 1}. ${item.injector.displayName}    (${item.path || "(not installed)"})\n`,
      );
    });
    io.out("Toggle (1-N), 's' to skip, enter to confirm: ");
    const line = await readLineOf(io);
    if (line === null) return [];
    const input = line.trim();
    if (input === "") return items.filter((item) => item.selected).map((item) => item.injector);
    if (input === "s" || input === "S") return [];
    const index = Number(input);
    if (!Number.isInteger(index) || index < 1 || index > items.length) {
      io.out(`Invalid input ${JSON.stringify(input)}\n`);
      continue;
    }
    items[index - 1]!.selected = !items[index - 1]!.selected;
  }
}

export async function runInstall(
  args: string[],
  io: IO,
  options: InstallOptions = {},
): Promise<number> {
  let flags;
  try {
    flags = parseFlags(args, {
      strings: ["home", "agents"],
      numbers: [],
      booleans: ["yes", "pin", "skip-files", "skip-agents"],
      arrays: [],
    });
  } catch (err) {
    io.out(`${message(err)}\n`);
    return 2;
  }
  if (flags.positionals.length > 0) {
    io.out(`Error: unexpected args: ${flags.positionals.join(" ")}\n`);
    return 2;
  }

  const version = options.version ?? VERSION;
  const env = envOf(io);
  const home = flags.strings.get("home") || defaultHome(env, homeOf(io));
  const yes = flags.booleans.has("yes");
  const pin = flags.booleans.has("pin");
  const skipFiles = flags.booleans.has("skip-files");
  const agentsFlag = flags.strings.get("agents") ?? "";
  const skipAgents = flags.booleans.has("skip-agents") || agentsFlag === "none";
  const explicitAgents = agentsFlag === "" || agentsFlag === "none"
    ? undefined
    : agentsFlag.split(",").map((name) => name.trim()).filter(Boolean);

  const ctx: AgentContext = {
    homeDir: homeOf(io),
    env,
    platform: platformOf(io),
  };
  const all = createInjectors(ctx);

  let injectors: AgentInjector[];
  if (skipAgents) {
    injectors = [];
  } else if (explicitAgents) {
    injectors = explicitAgents
      .map((name) => all.find((injector) => injector.name === name))
      .filter((injector): injector is AgentInjector => injector !== undefined);
  } else if (yes) {
    injectors = [];
    for (const injector of all) {
      if ((await injector.detect(ctx)).installed) injectors.push(injector);
    }
  } else {
    injectors = await promptAgentSelection(io, all, ctx);
  }

  if (!yes) {
    io.out("\nReview:\n");
    if (!skipFiles) {
      io.out(`  + ${home}/                      (dir, 0700)\n`);
      io.out(`  + ${home}/config.json           (0600, empty skeleton)\n`);
      io.out(`  + ${home}/config.example.json   (0600, examples)\n`);
    }
    for (const injector of injectors) {
      io.out(
        `  ~ ${injector.configPath(ctx)}                  (merge sshmng entry, backup -> .bak.<ts>)\n`,
      );
    }
    const answer = await promptConfirm(io.out, () => readLineOf(io), "Proceed?", false);
    if (answer.error !== undefined || !answer.confirmed) {
      io.out("Aborted.\n");
      return 0;
    }
  }

  io.out("Executing:\n");
  if (!skipFiles) {
    try {
      await scaffoldHome(home, {});
    } catch (err) {
      io.out(`  [FAIL] ScaffoldHome: ${message(err)}\n`);
      return 1;
    }
    io.out(`  [ok] Created ${home} (0700)\n`);
    io.out(`  [ok] Wrote ${home}/config.json (0600)\n`);
    io.out(`  [ok] Wrote ${home}/config.example.json (0600)\n`);
  }

  const entry = buildEntry(home, pin, version);
  for (const injector of injectors) {
    const file = injector.configPath(ctx);
    try {
      await injector.inject(file, entry);
    } catch (err) {
      io.out(`  [FAIL] ${injector.displayName}: ${message(err)}\n`);
      return 1;
    }
    io.out(`  [ok] Injected sshmng into ${file}\n`);
  }

  io.out("\nVerifying (doctor):\n");
  const doctorCode = await runDoctor([], io, {
    home,
    expectedEntries: [entry],
    findNpx: options.findNpx,
    nodeVersion: options.nodeVersion,
  });
  if (doctorCode === 1) {
    io.out("\nSetup completed with errors. Run 'sshmng doctor' for details.\n");
    return 1;
  }
  if (doctorCode === 2) {
    io.out("\nSetup completed with warnings. Run 'sshmng doctor' for details.\n");
  }

  io.out("\nSetup complete!\n\n");
  io.out("Next steps:\n");
  io.out("  1. Restart your Agent to load the new MCP config\n");
  io.out("  2. Ask Agent: \"list_ssh_servers\"\n");
  io.out("  3. Add servers by asking Agent \"add an SSH server named ...\"\n");
  io.out(`     Or manually edit ${home}/config.json (see config.example.json for examples)\n`);
  return 0;
}
```
